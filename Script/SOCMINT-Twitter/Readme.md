# Jieyab ft Xquik 

## Data Source 

1. Xquik API 
2. Cookie (your account cookie session) 
3. Wayback Machine 

## Setup

```bash
pip install -r requirements.txt
```

Edit `config.ini.example` to config.ini 

## Run Local Web Server 

```bash
python app.py
```

Open `http://127.0.0.1:5000`
